# c_basic_test

C 语言练习仓库，用 Visual Studio 保存学习过程中的示例代码。

## 项目

### Project1

C 语言基础语法练习合集：输入输出、分支与循环、数组、函数、常见算法（素数、二分查找、猜数字小游戏）等。

> `test01.c` 里的示例默认处于注释状态，当作学习笔记查看。想运行某一段，把对应代码取消注释后按 `F5`。

### Project2

扫雷游戏练习（目前只有基础框架，待完善）。

## 如何运行

1. 用 Visual Studio 打开 `Project1\Project1.slnx` 或 `Project2\Project2.slnx`
2. 选择 `x64` / `Debug`
3. 按 `F5` 编译运行

> 解决方案使用 `.slnx` 格式，需要较新版本的 Visual Studio（2022 17.14 及以上或 Visual Studio 2026）。
